# 兼容性

## 已测试环境

已提交的证据使用了：

- Node.js 22.16.0 记录离线运行；包声明支持 Node.js 20+。
- Godot 4.7.2 stable，用于无头、编辑器和导出检查。
- macOS 主机原生启动证据，以及 Linux/X11 运行时包导出配置。

CI 在 Ubuntu 上使用 Node.js 20 运行确定性 Node.js 检查。Godot 集成保留为本地或平台相关检查，因为当前证据依赖 Godot 编辑器/运行时和原生 GUI 环境。

## 兼容性策略

EventAsset、能力、主题或运行时契约的变更必须使用显式版本和迁移行为。看似兼容的显示名称变更不能改变机器 ID。影响生成输出的变更必须保留源映射和指纹证据，或明确更新这些证据。

## Godot 命名

CODA 是与 Godot 配合工作的独立项目，不声称获得 Godot Foundation 背书，也不使用 Godot 标志作为项目品牌。提及 Godot 时使用其官方大小写形式。
