# 提交体验反馈

这个项目会根据真实的首次体验持续改进。如果页面、示例、命令或 Godot 操作让你不清楚，或者你在某一步停住了，请用自己的话告诉我们发生了什么。

[打开 GitHub 体验反馈表单](https://github.com/guileen/godot-coda-engine/issues/new?template=feedback.md&title=%5BFeedback%5D%20)

不需要审阅源代码。以下信息最有帮助：

- 你当时想完成什么；
- 你在哪一步卡住；
- 你看到了什么、原本期待什么；
- 你使用了哪个页面、指南、示例或命令。

欢迎附截图。发布前请删除密码、令牌、私人项目文件和其他敏感信息。反馈会公开展示，因为它会直接影响下一轮迭代；请不要放入不适合公开的内容。

如果是可以稳定复现的实现问题，请改用 [Bug 报告模板](https://github.com/guileen/godot-coda-engine/issues/new?template=bug_report.md)。
