# CODA 用户使用手册

这份手册带你从打开 CODA 开始，完成三件事：看懂一个游戏流程、试着添加流程步骤、观察奖励与具身演示。你不需要先读代码，也不需要先学会 CODA 语法。

如果有人已经替你打开了程序，直接从[找到奖励流程](#2-找到奖励流程)开始。若你只参加试玩，请看[体验说明](../demos/体验说明.md)。

## 1. 打开 CODA

### macOS：双击打开

1. 找到 CODA 项目文件夹。它是同时放着 `README.zh-CN.md` 和 `project.godot` 的文件夹。
2. 双击里面的 **体验 CODA 事件编辑器.command**。
3. 等 Godot 窗口打开。Godot 4.7 或更新版本需要安装在 `/Applications/Godot.app`。

如果系统拦截了 `.command` 文件，可在 Finder 中对它点右键，选择“打开”，然后按系统提示再次确认。若出现“需要安装 Godot 4.7 或更新版本”，先安装该版本，再双击入口。

### 其他系统：从 Godot 打开

启动 Godot 4.7 或更新版本，在项目管理器中选择“导入”，选中 CODA 项目文件夹里的 `project.godot`，再打开该项目。项目文件夹就是包含 `project.godot` 的那一层。

## 2. 找到奖励流程

项目打开后，在 Godot 编辑器右侧找到 **CODA 事件** 面板。事件列表中选择 **应用奖励**。面板里主要有四个区域：

- **事件列表**：选择要查看的游戏事件，例如“应用奖励”。
- **添加步骤**：搜索一个步骤类型，并决定它插入在哪里。
- **流程**：按实际执行顺序显示步骤；条件分支会显示在对应步骤下面。
- **步骤设置**：选中一个步骤后，在这里查看说明、填写参数或预览修改。

第一次打开时，先在“流程”页点一个步骤。右侧会切换到“步骤设置”，显示它的用途和可编辑内容。看完后点回“流程”即可继续浏览。

奖励流程表达的是：检查奖励是否大于 0；符合条件时把奖励加到当前积分；播放积分变化；更新奖励记录并给出反馈。奖励为 0 时不增加积分，后续成功步骤也不会执行。

## 3. 添加一个步骤

添加的内容一开始只是草稿。只有点“确认这一步”才会写入流程；点“取消”会丢弃草稿。

1. 确认事件列表里选中了“应用奖励”。
2. 在“流程”页点一个步骤，作为插入位置的参照。新步骤默认接在它后面。
3. 在“添加步骤”区域的 **找步骤** 输入名称，例如“条件分支”或“读取信息”。列表会按名称筛选。
4. 在 **放在** 选择位置：接在当前步骤后面、插在它前面，或放在流程末尾。选中条件分支时，还可以选“条件成立时”或“条件不成立时”。
5. 在 **做什么** 选择步骤类型。下方说明会解释这个步骤的作用。
6. 点 **添加步骤**。CODA 会临时把它放进流程树，并切到“步骤设置”。
7. 按页面提示填写内容。若选的是“读取信息”，例如先选“目标界面”，再选要读取的字段，并为读取结果起名。
8. 确认内容后点 **确认这一步**。不想保留时点 **取消**。

确认按钮不可用或提示内容未填完整时，按“步骤设置”页面的提示补齐。若页面说明该步骤类型目前不能通过图形方式补全，请点“取消”；不要为了继续而填写不理解的内容。

## 4. 修改条件或计算

修改已有条件或计算时，先在“流程”里选中对应步骤，再到“步骤设置”页编辑。

- **计算步骤**：例如“当前积分 + 奖励”。修改后点“预览计算修改”，检查新旧内容和预览结果。确认要采用时，在“更多操作”中选择 **确认已预览的修改**；不采用时选择 **取消预览**，原内容会保留。
- **条件分支**：按页面里的值、比较方式和目标值调整，然后点“预览条件修改”。检查条件和执行结果后，再从“更多操作”选择 **确认已预览的修改**，或选择 **取消预览**。
- **改错了**：在“更多操作”中选择 **撤销**；需要恢复撤销内容时选择 **重做**。

预览用于先看清将要改变什么。看到预览不代表已经写入；只有确认后修改才会保存。

## 5. 运行奖励样例

1. 在项目文件夹里双击 **体验 奖励流程.command**。如果编辑器挡住了画面，可以先最小化编辑器。
2. 画面显示“领取关卡奖励”，初始积分为 **100**，并显示上一条奖励记录。
3. 点 **领取奖励 +25**。你应看到积分从 100 变化到 **125**，奖励记录更新，并出现结算反馈。
4. 点 **重置样例**，恢复初始状态。
5. 点 **验证条件：奖励为 0**。积分应保持 100，原奖励记录不变；界面会标出条件未通过和后续步骤跳过。

如果结果和这里写的不一致，先点“重置样例”再试一次，并记录点击了哪个按钮、画面出现了什么。

## 6. 运行具身姿态演示

在项目文件夹里双击 **体验 具身演示.command**。这是一个 Godot 仿真画面，展示 GDBot 的头部骨骼姿态和表情。

- 点 **攻击后收势** 或 **高位防御**，观察头部姿态变化及执行状态。
- 动作进行时点 **中断并安全回中**，观察动作中止后回到安全中立姿态。恢复完成后，可以试点 **续接剩余动作（仿真）**。
- 点表情按钮，观察面部表情变化。
- 点 **模拟外部占用** 后再尝试发起动作，观察系统拒绝冲突写入；再次点它可释放占用。
- **模拟对象失效** 用于观察目标对象失效时的拒绝反馈；**重置演示** 用于恢复演示状态。

本演示展示的是受约束的运动计划怎样进入 Adapter 并驱动仿真骨骼。它只控制 GDBot 头部姿态和表情，不是完整的全身运动控制器，也没有连接真实机器人、电机或传感器。因此它不能证明真实机器人的平衡、接触安全或动作自然度。

## 7. 遇到问题时

| 看到的情况 | 可以怎么做 |
| --- | --- |
| 双击入口后没有窗口 | 确认 Godot 4.7 或更新版本已安装在 `/Applications/Godot.app`；等待几秒再看 Dock 或窗口列表。 |
| 找不到“CODA 事件”面板 | 确认打开的是 CODA 项目（包含 `project.godot` 的文件夹），等待项目加载完成；仍没有时请记录画面并联系主持人。 |
| 提示先选择事件 | 在事件列表中先点“应用奖励”，再添加步骤。 |
| 不确定新步骤会加在哪里 | 查看“放在”当前选项；默认是接在刚选中的步骤后面。取消草稿不会改变原流程。 |
| 预览和预期不一致 | 先取消预览或草稿，保留原内容，并记录你修改前后的文字和看到的提示。 |
| 奖励样例状态混乱 | 点“重置样例”，再从初始画面开始。 |
