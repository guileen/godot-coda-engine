# CODA 语法小抄

```coda
模块 界面.奖励
事件 领取奖励（当前积分，奖励） [标识：界面.奖励.领取]：
  令 新积分 为 当前积分 加 奖励
  若（奖励 大于 0）：
    等待 界面.播放数字动画@1(目标：积分标签, 起始值：当前积分, 结束值：新积分, 时长：动画时长)
```

上例是中文别名预览；它说明中文使用者最终应看到的命名方式。当前命令行可执行版本使用项目契约的机器标识，见 [`examples/reward-claim.coda`](../../examples/reward-claim.coda)。

| 写法 | 含义 |
| --- | --- |
| `模块` | 为一组事件命名。 |
| `事件（输入） [标识：…]` | 声明可触发流程和输入。 |
| `令` | 命名这一步计算出的值。 |
| `若` | 条件成立时执行缩进内容。 |
| `执行` | 调用立即完成的已声明能力。 |
| `等待` | 调用跨帧完成的已声明能力。 |
| `发出` | 发布已声明的游戏事件。 |

英文关键字 `module`、`event`、`id`、`let`、`if`、`do`、`await`、`publish` 同样可用。当前文本入口覆盖事件、输入、局部值、条件、同步动作、等待动作与事件发布。能力必须在项目清单中声明；当前未声明的 Godot API、复杂算法和任意反射请使用 GDScript。
