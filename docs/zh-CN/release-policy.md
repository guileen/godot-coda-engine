# 发布策略

CODA 的发布以证据为依据。候选版本必须具备版本化源资产和契约集、可复现生成、通过的离线测试、受影响的 Godot 检查，以及导出界面发生变化时的运行时边界审计。

## 版本规则

- 补丁版本包含兼容修复、文档和证据更新。
- 次版本可以增加向后兼容的命令、能力、主题和编辑器行为。
- 主版本只有在提供明确迁移说明时，才可以改变 EventAsset、运行时或生成代码契约。
- 当输入、输出、生命周期或失败语义发生变化时，能力和主题 ID 分别独立版本化。

## 发布门槛

发布前，项目所有者必须确认仓库所有权、许可证、发布说明、支持的 Godot/Node 版本以及准确的证据命令。GitHub tag 或 Pages 部署不能替代这些决定。

## 当前状态

E0 实现基线已经完成并在本地验证。软件代码采用 MIT，文档/网站内容采用 CC BY 4.0。项目所有者已选择 CODA 作为首个 GitHub Pages 版本的工作品牌；这不代表已完成商标清权。可选的 `coda.ipub.io` 入口暂缓。
