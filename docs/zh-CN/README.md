# Godot CODA Engine 中文文档

Godot CODA Engine（简称 CODA）是面向 Godot 的游戏逻辑引擎。本目录维护中文文档，与英文文档分开演进，避免不同语言的正文混在同一个文件中。

## 从想法到游戏流程

1. [5 分钟认识 CODA](5-minutes-coda.md) — 先看领取奖励这样的游戏行为怎样写成流程。
2. [写出第一个游戏流程](first-game-flow.md) — 把“发生什么”拆成输入、条件、等待与下一步。
3. [CODA 语法小抄](language.md) — 写作时回来看每个词的准确含义与当前边界。

第一次使用 CODA 或需要图形界面逐步操作时，请先看[用户使用手册](user-manual.md)。只参加试玩时，请看[体验说明](../demos/体验说明.md)。

需要打开现有 Godot 项目时，再阅读[快速开始](quick-start.md)。关于当前能力、生成代码和结构化资产的技术细节，请读[核心概念](concepts.md)与[范围与排障](scope-and-troubleshooting.md)。
