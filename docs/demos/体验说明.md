# CODA 体验说明

这页给试玩者和观察者看。试玩不需要查找代码、打开终端或了解 Godot 项目结构。

## 打开奖励流程编辑器

在仓库文件夹中双击 **体验 CODA 事件编辑器.command**。Godot 打开后，在右侧找到 **CODA 事件** 面板，选中“应用奖励”流程。选择流程中的步骤可以查看说明；添加步骤时按“找步骤 → 放在 → 做什么 → 添加步骤”操作，面板会提示下一步。要试玩结果，关闭或最小化编辑器，再双击 **体验奖励流程.command**。

奖励演示里可以点击“领取奖励 +25”，观察积分和反馈变化；也可以点击奖励为 0 的选项，观察条件不成立时流程如何反馈。

## 打开具身演示

双击 **体验具身演示.command**。用屏幕上的按钮尝试攻击后收势、高位防御、中断回中、续接剩余动作和表情变化，也可以观察外部占用时的拒绝反馈。

这个演示在 Godot 中驱动 GDBot 的头部骨骼姿态和面部表情，展示 CODA 生成的运动计划如何进入 Adapter。它不是完整机器人控制器，也不连接真实电机。

## 试玩时请评价

- 文字、步骤和分支是否自然易懂？哪里让你停下来想？
- 添加草稿步骤时，能否知道它会插在哪里、下一步该做什么？
- 预览和确认是否让你看清改动？运行结果是否符合预期？
- 具身动作和反馈是否容易看懂？你以为它证明了什么？

观察者负责提前打开体验。参与者只需从已打开的界面开始，不需要学习启动方式、文件位置或内部术语。
