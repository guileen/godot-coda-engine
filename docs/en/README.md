# Godot CODA Engine English documentation

Godot CODA Engine (CODA for short) is a game-logic engine for Godot. The English documentation is maintained in this directory so it can evolve independently from the Chinese translation.

## From idea to gameplay flow

1. [Meet CODA in 5 minutes](5-minutes-coda.md) — see a familiar reward-claim behavior written as a flow.
2. [Write your first gameplay flow](first-game-flow.md) — break “what happens” into inputs, conditions, waits, and the next step.
3. [CODA language reference](language.md) — return here while writing for the exact meaning and current boundary of each word.

Read [Quick start](quick-start.md) when you are ready to open the existing Godot project. For technical detail on the current capabilities, generated code, and structured assets, see [Core concepts](concepts.md) and [Scope and troubleshooting](scope-and-troubleshooting.md).
