# Share product feedback

This project is being improved through real first-user sessions. If a page, example, command, or Godot step is unclear or stops you, tell us what happened in your own words.

[Open the feedback form on GitHub](https://github.com/guileen/godot-coda-engine/issues/new?template=feedback.md&title=%5BFeedback%5D%20)

You do not need to inspect the source code. The most useful report includes:

- what you were trying to accomplish;
- the step where you got stuck;
- what you saw and what you expected;
- the page, guide, example, or command you used.

A screenshot is welcome. Please remove passwords, tokens, private project files, and other sensitive data before posting. Feedback is public because it helps shape the next iteration; do not include anything you would not publish.

For a reproducible implementation problem, use the [bug report template](https://github.com/guileen/godot-coda-engine/issues/new?template=bug_report.md) instead.
