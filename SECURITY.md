# Security policy / 安全政策

Do not report suspected vulnerabilities in a public issue. Use GitHub private vulnerability reporting or the repository's private contact mechanism.

请不要在公开 issue 中报告疑似漏洞。请使用 GitHub 私密漏洞报告，或仓库的私密联系机制。
