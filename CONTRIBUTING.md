# Contributing to CODA / 为 CODA 贡献代码

This root file is GitHub's contribution entry point. The complete language-specific guides are maintained separately:

这是 GitHub 识别的贡献入口。完整的语言专属指南分开维护：

- [English contribution guide](docs/en/contributing.md)
- [中文贡献指南](docs/zh-CN/contributing.md)

The short rule is the same in both languages: keep the structured asset, generated runner, and E0 runtime boundaries explicit; preserve stable IDs, source maps, diagnostics, and tests.

两种语言遵循同一原则：明确维护结构化资产、生成 runner 和 E0 运行时边界；保留稳定 ID、源映射、诊断信息和测试。

Software contributions use MIT; documentation contributions use CC BY 4.0. The `Made with CODA` badge is encouraged under [`TRADEMARKS.md`](TRADEMARKS.md), but it is not a condition of using the software.

软件贡献采用 MIT；文档贡献采用 CC BY 4.0。`Made with CODA` 徽章遵循 [`TRADEMARKS.md`](TRADEMARKS.md)，但不是软件使用条件。
