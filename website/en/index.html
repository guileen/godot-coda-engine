What is already real

The promise is narrow.
The evidence is not.

01

One semantic source

EventAsset is saved, versioned, checked, and regenerated. The tree—not a text draft or generated file—is the source of truth.

02

One managed wait

Completion, cancellation, timeout, owner loss, and late callbacks compete through one gate and settle a run once.

03

One traceable output

Every generated step carries a stable marker and source-map path back to its event, node, field, and backend.

The shape of one event

Structured first.
Executable second.

CODA stays deliberately small at the runtime edge. The authoring model can be expressive; the exported game only carries the runner, E0 lifecycle library, and declared capabilities it needs.

  3. 02 ExecutionPlan

  5. 03 GDScript

    Private runner, stable markers, source map.

Know the edge

Clear boundaries make
the useful part trustworthy.

In the E0 release

  • Sequence, conditions, local bindings, and explicit outputs
  • Constrained loops, synchronous calls, managed awaits
  • Versioned capability and publish/subscribe boundaries
  • Cancellation, timeout, owner invalidation, and cleanup

Not promised here

  • spawn/join, error blocks, E1/E2
  • Long-lived text source files or LSP
  • Arbitrary Godot reflection
  • Runtime interpretation of text or assets
