# Godot CODA Engine trademark and brand policy / Godot CODA Engine 商标与品牌政策

## Purpose / 目的

Godot CODA Engine is an open-source software project; CODA is its short name. The code license is intended to maximize adoption. The Godot CODA Engine name, CODA wordmark, icon, and `Made with CODA` badge identify project origin and are governed separately so that users can refer to the project truthfully without implying official Godot endorsement.

Godot CODA Engine 是一个开源软件项目，CODA 是其简称。代码许可证以最大化采用为目标。Godot CODA Engine 名称、CODA 文字标、图标和 `Made with CODA` 徽章用于标识项目来源，单独受本政策管理；用户可以真实提及项目，但不得暗示获得 Godot 官方背书。

## Software use / 软件使用

The MIT License does not require a game or application to display a CODA logo. You may use, modify, and distribute the software under the terms of [`LICENSE`](LICENSE), while preserving the required copyright and license notice.

MIT License 不要求游戏或应用展示 CODA logo。你可以按照 [`LICENSE`](LICENSE) 使用、修改和分发软件，同时保留许可证要求的版权和许可证声明。

## Recommended attribution / 推荐署名

We strongly encourage projects that use CODA to include the [`Made with CODA`](brand/made-with-coda.svg) badge in a credits screen, splash screen, store page, project website, or documentation. This is a community and brand request, not a condition of the software license.

我们强烈建议使用 CODA 的项目在片尾、启动画面、商店页面、项目网站或文档中使用 [`Made with CODA`](brand/made-with-coda.svg) 徽章。这是社区和品牌倡议，不是软件许可证的使用条件。

## Permitted badge use / 徽章允许用法

- Use the provided assets without changing the CODA wordmark or suggesting that CODA endorses the project.
- You may say “Made with CODA” only when the project actually uses CODA.
- You may link the badge to <https://github.com/guileen/godot-coda-engine> or the localized CODA website.
- Official CODA Showcase listings may require the badge and a link as a condition of being listed as an official showcase entry.

- 可以使用仓库提供的资源，但不得修改 CODA 文字标，也不得暗示 CODA 为项目背书。
- 只有项目实际使用 CODA 时，才可以写“Made with CODA”。
- 可以将徽章链接到 <https://github.com/guileen/godot-coda-engine> 或 CODA 的多语言网站。
- CODA 官方 Showcase 收录可以要求徽章和链接，作为官方 Showcase 条目的收录条件。

## Not permitted / 不允许的用法

- Do not use `CODA` alone in a way that falsely suggests an official Godot product, company, or endorsement; the full project name is Godot CODA Engine and remains an independent project.
- Do not use the badge to imply certification, partnership, sponsorship, or endorsement without written permission.
- Do not remove or alter the attribution language in a way that misleads users about project origin.

- 不得单独使用 `CODA` 造成 Godot 官方产品、公司或背书的虚假印象；本项目完整名称为 Godot CODA Engine，并保持独立项目身份。
- 未经书面许可，不得使用徽章暗示认证、合作、赞助或官方背书。
- 不得以误导用户判断项目来源的方式删除或修改署名内容。
